# docs/context

このリポジトリの作業状況と技術的な学びを、Asia/Tokyo の日付で日本語で残します。新しい作業を始めるときは最新の `*-handoff.md` を読みます。

- `YYYY-MM-DD-handoff.md`: 現状、反映した変更、検証、未決事項、次に必要な作業。最新のファイルを現状の正とし、過去分は履歴として残します。
- `YYYY-MM-DD-learnings.md`: その日に確認した挙動、落とし穴、判断の理由。将来の作業に再利用できる事実を記録します。

日付が変わったら、新しい handoff を単体で現状が分かるように作成し、解決済みの途中経過は繰り返さないでください。認証情報、モデルの入出力や実データは記録しません。
